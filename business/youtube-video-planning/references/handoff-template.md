# Handout Template (Reference)
Template file lives at workspace: `.hermes/workspace/youtube-handoff/handoff-template.md`

Fields:
- video_id, business, clickup_task_url, video_type
- Concept & Script (title, hook, outline)
- Seed Images (prompts, reference URLs)
- Thumbnail Design (specs, style, text, variants)
- Description (draft with CTAs, tags, chapters)
- Transcript / Captions (source method: generate-from-script / extract-from-url / manual; caption format .srt/.vtt)
- Deliverables Expected (video file, thumbnail PNG, description markdown, transcript, seed outputs)
- Return / delivery method (shared path or message)

Always include: ClickUp task reference, business space, status (`APPROVED` before remote agent starts), return path.
